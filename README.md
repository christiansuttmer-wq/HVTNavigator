# HVTNavigator – Android-App

Dieses öffentliche Repository dient ausschließlich zur Verteilung signierter HVTNavigator-APK-Updates über **GitHub Releases**.

Der Android-Quellcode, Signaturschlüssel und Zugangsdaten werden hier **nicht** veröffentlicht.

## Installation und Updates

Die jeweils veröffentlichte APK ist unter [Releases](https://github.com/christiansuttmer-wq/HVTNavigator/releases) zu finden.

Der HVTNavigator prüft beim Start auf ein neueres **stabiles** Release. Installation und Berechtigung werden durch Android bestätigt.

**Wichtig:** APKs müssen den Paketnamen `de.bauda.hvtnavigator`, fortlaufende `versionCode`-Werte und denselben Release-Signaturschlüssel verwenden. Der Dateiname der APK im Release lautet `HVTNavigator-release.apk`.

*Das Repository enthält keine Installationsdatei, solange noch kein Release veröffentlicht wurde.*
